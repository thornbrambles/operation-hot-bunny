# Roadmap

## v0.2 browser edition

- One-page competitor editor with paste, drag/drop, and file selection.
- Direct Twitch WebSocket and YouTube browser-authorized chat connections.
- Combined number voting, account deduplication, vote changes, ties and undo.
- Winner/champion presentation and OBS window-capture focus mode.
- Browser-local saving and portable bracket backups.

## External acceptance still needed

- Configure Twitch and Google OAuth applications at the deployed origin.
- Verify one Twitch vote, one YouTube vote, a changed vote, and ending a vote during a real broadcast.
- Check the browser window capture in her OBS scene.

## Possible next steps

- Optional vote timer and shuffled seeding/byes.
- Assess YouTube streaming API support and quota savings for browsers.
- Optional relay or peer connection for an independently loaded OBS Browser Source, while retaining the fully local mode.
- More stage themes.

No hosted vote database or backend is part of this version.
